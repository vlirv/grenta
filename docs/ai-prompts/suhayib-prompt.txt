4. SHARED JAVASCRIPT (assets/js/main.js) - use these, do not rewrite them
==================================================================
  Malaab.load(key)            -> data from localStorage, or the demo data in data.js
                                 (returns null if the key does not exist yet)
  Malaab.save(key, value)     -> save to localStorage
  Malaab.nextId(list)         -> next free id for a list of objects with "id"
  Malaab.currentUser()        -> logged-in user object or null
  Malaab.requireLogin(roles)  -> protect a page. roles: ["player"], ["owner"], ["admin"]
                                 or nothing = any logged-in user. Returns the user or null
                                 (then it already redirected - just "return").
  Malaab.showAlert("#formAlert", "Text", "success" | "danger" | "warning" | "info")
  Malaab.validate(form)       -> true if the form is valid
  Malaab.formatPrice(120)     -> "120 LYD"
  Malaab.escapeHtml(text)     -> ALWAYS use for user text you put into innerHTML
  Malaab.go("booking/receipt.html?id=5")   -> path from the project root
  Malaab.url("fields/field.html?id=1")     -> full link for href
  Malaab.refreshNavbar()      -> refresh bell count / user icon after changing data

JavaScript style:
  - Wrap everything in: document.addEventListener("DOMContentLoaded", function () { ... });
  - const / let, double quotes, 2-space indent, semicolons, small named functions.
  - Read data with Malaab.load, change the array, save with Malaab.save, then re-draw.
  - Read URL parameters with: new URLSearchParams(location.search).get("id")
  - Dates as "YYYY-MM-DD" strings, times as "HH:MM" (24h).
  - Use confirm() before cancel/delete actions.
  - Comment at the top of the file: what the page does and "(Your name)".

5. DATA FORMATS - everyone MUST use exactly these keys and fields
==================================================================
users:  { id, name, email, phone, city, password, role: "player"|"owner"|"admin",
          status: "active"|"pending"|"rejected"|"suspended" }
fields: { id, name, city, area, size: "5-a-side"|"7-a-side"|"11-a-side", price (per hour),
          rating, ownerId, lat, lng, facilities: ["parking","showers","lights","cafe"],
          status: "active"|"pending"|"rejected"|"suspended"  (missing status = "active"),
          phone, description, rules: [], photos: [] }
bookings: { id, userId, fieldId, date, time, hours, total, discount, paid,
          payment: "deposit"|"full"|"field", coupon, recurring: false,
          status: "pending"|"confirmed"|"rejected"|"cancelled"|"completed",
          reason (reject reason), createdAt (ISO string) }
coupons: { code, type: "percent"|"fixed", value, fieldId (optional = only that field),
          expires: "YYYY-MM-DD", maxUses (optional), used (optional, number) }
notifications: { id, userId (optional), type: "booking"|"offer"|"message"|"support",
          icon: "bi-...", title, text, time, read: false }
reviews: { id, fieldId, userId, bookingId, stars: 1-5, comment, date, hidden: false }
tickets: { id, userId, subject, category, message, status: "open"|"answered"|"closed",
          date, replies: [ { from: "user"|"support", text, date } ] }
messages: { id, bookingId, fieldId, fromId, toId, text, date }
cart:   { fieldId, date, time, hours, recurring, price, heldUntil (ms timestamp) }
schedule: { "<fieldId>": { slotMinutes: 60, blocked: ["YYYY-MM-DD"],
          days: { sat: { open: "16:00", close: "23:00", closed: false }, sun: {...},
                  mon, tue, wed, thu, fri } } }
contactMessages: written by Mouen's contact page.

Demo accounts (password 123456): user@demo.ly (player id 1), owner@demo.ly (owner id 2),
admin@demo.ly (admin id 3). Owner id 2 owns fields 1-6.

Business rules (same for everyone):
  - Default opening hours 16:00-23:00, 1-hour slots, if no schedule is saved.
  - Price = field.price x hours. Deposit = 30% of the total (rounded).
  - A chosen slot is held for 10 minutes (cart.heldUntil).
  - A slot is taken if a booking with the same fieldId+date+time has status
    "pending" or "confirmed".
  - Player may cancel until 24 hours before the start time.
  - Bookings start as "pending"; the owner accepts ("confirmed") or rejects ("rejected").
  - A booking whose date+time has passed and was confirmed counts as "completed".
  - Demo card: 4242 4242 4242 4242 succeeds, any card ending in 0002 is declined.
  - Only fields with status "active" (or no status) are shown to players.
  - When something happens to a user, add a notification for them (with userId).

Links between pages (use these exact URLs and parameters):
  fields/field.html?id=FIELD_ID        fields/reviews.html?field=FIELD_ID
  fields/ticket.html?id=TICKET_ID      booking/booking.html?field=FIELD_ID
  booking/checkout.html (reads "cart") booking/receipt.html?id=BOOKING_ID
  booking/messages.html?booking=BOOKING_ID
